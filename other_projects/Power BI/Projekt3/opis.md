README – Wine Analysis Dashboard
Na podstawie przesłanego dashboardu Power BI sceran1.docx oraz szablonu README Redame.docx przygotowałem gotowy opis projektu.

Opis projektu
Wine Analysis Dashboard to interaktywny raport stworzony w Microsoft Power BI, którego celem jest analiza danych dotyczących win pochodzących z różnych krajów świata. Dashboard umożliwia analizę ocen użytkowników, cen win, liczby recenzji, udziału win premium oraz porównanie różnych odmian win (varietal).
Raport został zaprojektowany z myślą o szybkim dostępie do kluczowych informacji i wspieraniu analizy rynku winiarskiego za pomocą czytelnych wizualizacji oraz wskaźników KPI.

Cel projektu
Celem projektu było stworzenie nowoczesnego dashboardu Business Intelligence umożliwiającego:
analizę ocen win, 
analizę średnich cen, 
porównywanie krajów pod względem liczby recenzji, 
identyfikację najpopularniejszych odmian win, 
analizę win premium, 
porównanie relacji ceny do jakości, 
filtrowanie danych według rodzaju wina. 
Projekt pokazuje wykorzystanie Power BI do analizy danych oraz prezentacji informacji w przejrzystej i interaktywnej formie.

Zastosowane narzędzia
Projekt został wykonany z wykorzystaniem:
Microsoft Power BI Desktop 
Power Query 
DAX (Data Analysis Expressions) 
Model relacyjny danych 
Microsoft Excel / CSV jako źródło danych 

Funkcjonalności raportu
Dashboard umożliwia:
filtrowanie danych według rodzaju wina (Red, White, Rosé, Other), 
analizę liczby recenzji, 
analizę średniej oceny win, 
analizę średniej ceny, 
monitorowanie liczby win premium, 
analizę udziału win premium, 
analizę liczby krajów pochodzenia win, 
porównanie liczby recenzji według kraju, 
analizę zależności pomiędzy średnią ceną i średnią oceną, 
porównanie średnich ocen dla poszczególnych odmian win. 

Kluczowe wskaźniki KPI
Raport prezentuje najważniejsze wskaźniki biznesowe, takie jak:
Liczba recenzji 
Średnia ocena win 
Średnia cena 
Liczba win premium 
Procent win premium 
Liczba krajów 

Umiejętności zaprezentowane w projekcie
Podczas realizacji projektu wykorzystano następujące umiejętności:

Najważniejsze analizy
Raport umożliwia odpowiedź na pytania biznesowe, takie jak:
Które kraje posiadają największą liczbę recenzowanych win? 
Czy wyższa cena oznacza wyższą ocenę wina? 
Jakie odmiany win uzyskują najwyższe oceny? 
Jaki jest udział win premium w całym zbiorze danych? 
Które typy win dominują na rynku? 

Podsumowanie
Projekt Wine Analysis Dashboard prezentuje praktyczne zastosowanie narzędzia Microsoft Power BI do analizy danych z branży winiarskiej. Dzięki zastosowaniu wskaźników KPI, wykresów analitycznych, segmentatorów oraz interaktywnych wizualizacji raport umożliwia szybkie porównywanie jakości, cen i popularności win pochodzących z różnych krajów. Projekt stanowi przykład wykorzystania narzędzi Business Intelligence do eksploracji danych, wspierania decyzji biznesowych oraz tworzenia nowoczesnych dashboardów analitycznych.
